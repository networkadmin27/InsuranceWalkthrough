Instructions

  1. Log into your Google Workspace Admin console
  2. Expand the Apps drop-down
  3. Expand the Google Workspace drop-down and click Gmail
  4. Click Spam, phishing, and malware
  5. In the Organizational Units section toward the middle-left of the page, ensure your domain is selected
  6. Scroll to the Spam section
  7. If no list has been set up before, click Configure. Otherwise, click Add Another Rule
  8. Give the setting a description/name
  9. Check the Bypass spam filters for messages received from addresses or domains within these approved senders lists box
  10. Directly underneath, click Use existing list or Create or edit list
  11. If selecting Create or edit list:
    • The Manage address lists setting will open in a new tab
    • Click ADD ADDRESS LIST
    • Enter a name for the new list
    • Click ADD ADDRESS and enter our domain or a specific email address
    • Repeat for any additional domains/addresses
    • Click SAVE for this address list
    • Then, return to the original tab and click Use existing list
  12. Check the box for the list(s) with our domains/addresses, then close the popup
  13. Also check the Bypass spam filters and hide warnings for messages from senders or domains in selected lists box directly underneath the previous one
  14. Add the list with the Use existing list or Create or edit list options in the same way
  15. Click SAVE
