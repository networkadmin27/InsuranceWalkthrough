Instructions

  1. Log into your Microsoft 365 admin center
  2. Expand the Admin centers drop-down
  3. Click Exchange to open the Exchange admin center
  4. Expand the Mail flow drop-down
  5. Click Rules
  6. Click Add a rule and select the Create a new rule option
  7. Give the rule a name
  8. In the Apply this rule if drop-down, select The sender and domain is
  9. Add our domains in the specify domain popup and click Save
  10. In the Do the following drop-down, select Modify the message properties and set the spam confidence level (SCL)
  11. Select Bypass spam filtering from the specify SCL popup menu and click Save
  12. Click Next to go to the Set rule settings section
  13. Ensure Rule mode is set to Enforce, then click Next
  14. Once on the Review and finish section, click Finish
  15. Ensure the rule shows Enabled under Status
